# Hi, I'm Antonio

I'm interested in machine learning, statistics, optimization and scientific computing. Here I share my university and personal projects in C++, Python, R and MATLAB, from data analysis and modelling to numerical methods and software development.

## Selected projects

- **[Cardiovascular disease classification](https://github.com/antonio-arbizzani-tonelli/cardiovascular-classification-numpy)** — Classification from survey data using gradient boosting built with NumPy, with model comparisons and error analysis.
- **[LLM resource allocation](https://github.com/antonio-arbizzani-tonelli/llm-resource-allocation)** — Allocation of LLM workloads under GPU capacity and cost constraints, with Python and C++ implementations, cross-language checks and OpenMP benchmarks.
- **[Adaptive budget allocation](https://github.com/antonio-arbizzani-tonelli/adaptive-budget-allocation-online-learning)** — Online learning for advertising auctions with limited budgets, including budget pacing and adaptation to changing market conditions.
- **[Fluid-flow verification and validation](https://github.com/antonio-arbizzani-tonelli/fluid-flow-verification-validation)** — MATLAB analysis of simulated and experimental fluid flows, covering verification, validation and measurement uncertainty.
- **[Palmer Penguins statistical analysis](https://github.com/antonio-arbizzani-tonelli/palmer-penguins-statistical-analysis)** — Regression, model diagnostics, cross-validation and species classification in R.

Each repository includes the methods, results and instructions for running the code.
